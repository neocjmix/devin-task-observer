## 관리 기준

우선순위 P1/P2/P3로 남은 작업을 관리한다. 상세 체크리스트와 진행 상태는 GitHub 이슈를 따른다.

후속 작업 6개 중 B01은 검증 완료했고 나머지 5개는 미완료다. GitHub milestone `M3 · UI V2 후속 검증`에서 관리하며, M2 보류 항목 1개는 `legacy`로 분리한다. 마감일은 정하지 않았다. 상세 체크리스트·진행 상태는 이슈가 원본이고 이 문서는 그 색인이다.

## 담당과 순서

B01은 실제 개인 합성 세션으로 검증했다. 경로 변경 후 기존 창의 정상 재로드와 Devin의 명령 승인은 별개이며, 승인 없이 자동 전환된 것으로 보고하지 않는다. **B02의 개인 실사용은 사용자가 맡기로 했으며**, 에이전트는 익명화 결과 정리와 분석을 맡는다. B03–B05는 에이전트가 검증하되 로그인·접근성·추가 장비나 데이터 삭제 정책은 해당 범위의 사용자 판단이 필요하다. B06의 실제 개인 DB 대상도 사용자 선택이 선행한다.

B07은 현재 기본 기능의 선행 조건이 아니며 M2를 다시 사용할 때만 재평가한다.

## 백로그에 넣지 않은 의도적 경계

| 항목 | 현재 판단 |
|---|---|
| 정확한 기존 세션 탭 이동 | 미지원. ID 복사·실행 중 앱 활성화로 완료된 대체 경로 유지; 새 호환성 증거가 있을 때 재검토 |
| 다른 Devin provider/schema | 확인한 Local schema 17만 지원. 추측 기반 확장 안 함 |
| 옛 항목의 역할·확인 위치 추정 | 자동 추정 안 함. 새 보고부터 확립하는 계약 |
| workspace-only Git 사실의 추가 UI | 선택적 확장 후보. 현재 등록 리소스 기능의 미구현으로 취급하지 않음 |
| 독립 설치 패키지·서명·공증 | 현 alias 실행기의 지원 범위 밖. 배포 요구가 생기면 별도 범위 확정 |
| btw/fork/검색 기반 별도 세션 분석 | 채택하지 않은 실험 방향. 현재 경로에 재도입하지 않음 |
| M2 자동 모델 분석·모델/클라우드 확대 | 현재 제품 우선순위에서 제외 |

## 갱신과 종료

이슈를 닫으려면 해당 완료 조건의 실행 결과·실패/미검증·커밋 또는 증거 문서가 필요하다. 구현 완료와 실제 환경 검증 완료를 분리한다. 해결한 항목은 이 표와 이슈의 상태·검증 근거를 갱신한다. 우선순위나 범위가 바뀌면 이슈와 이 문서를 함께 수정한다.
