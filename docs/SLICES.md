## 기준

현재 고정 기준은 [BASELINE](BASELINE.md), 남은 일은 [BACKLOG](BACKLOG.md)다. 아래 완료는 기록된 범위의 구현을 의미하며 미검증 환경까지 포함하지 않는다. 각 슬라이스의 당시 수치·실패·한계를 소급 변경하거나 합산하지 않는다.

이전 개인 사용 기준은 [`998978a`](https://github.com/neocjmix/devin-task-observer/commit/998978a471007e1b29fc07e3ee2633e0a435d967)였다. 그 뒤 사용자 요청으로 UI V2와 경로 정정을 수행했고 새 기준을 고정했다. 원래 브랜치 `p0/desktop-probe`와 Draft PR #1은 유지한다.

## 다음 ID와 기록 형식

새 M3 구현의 다음 미사용 번호는 `M3-S06`이며 **이번 정리에서 예약하거나 구현하지 않았다**. UI-V2-S0–S8을 재사용하지 않는다. 다음 실행은 실제 승인 범위를 확인한 뒤 해당 ID를 예약하고 커밋 제목에도 붙인다.

새 기록은 H1·4행 메타데이터 뒤 `범위와 기준 → 구현 결과 → 검증 결과 → 남은 제약`을 사용한다. 실행 전에는 범위·수용 조건만 기록하고 완료 후 결과를 채운다. 문서 정리만인 이번 커밋은 새 제품 슬라이스로 세지 않는다.
