## 당시 기록

2026-10-30. 시작 기준선은 `f5fff46f1b7d8f516d2cb58efda497c44de8dd68`이다.
사용자가 개인 실사용 검증은 뒤로 미루고, 깊은 메뉴·스펙 설명 같은 문구를 정리하며
그래픽 요소를 조금 추가하도록 요청했다. M3의 상태 저장·보고·수집 계약은 그대로 둔다.

## 변경

- 태스크를 열면 각 항목의 값, 보고 상태, 마지막 변경 세션·시각이 바로 보인다.
  항목 하위 메뉴는 긴 값·근거·고정 여부 등 추가 확인에 사용한다.
- `태스크 → 참여 세션 → 개별 세션`을 `태스크 → 개별 세션`으로 줄였다.
  보고 켜짐/꺼짐도 태스크 메뉴에서 바로 확인한다. 메모는 펼친 태스크 안에 표시한다.
- 태스크/항목 ID, revision, 반복되던 보장사항 설명은 상세 정보로 이동했다.
  `능동보고 ON/OFF`, `지금 수집·상태 새로고침` 등은 짧은 제품 문구로 바꿨다.
- 작은 macOS 시스템 아이콘, 구분선, 본문과 출처의 글자 구분을 추가했다.
  읽기 전용 텍스트는 비활성 명령의 회색 글자 대신 네이티브 텍스트 뷰로 표시한다.
- 같은 제목의 태스크·항목도 사라지지 않도록 표시 문구와 네이티브 메뉴 내부 키를 분리했다.
- 메뉴를 읽는 동안 구조 재생성을 보류하고, 닫은 다음 타이머에서 최신 내용을 반영한다.
  수집은 계속 실행된다. 매 수집마다 열어 둔 하위 메뉴를 다시 만들지 않는다.
- 닫힌 메뉴를 갱신할 때 이전 rumps 콜백 참조도 해제하여 교체된 텍스트 뷰가 계속 쌓이지 않게 했다.

저장된 제목·보고값·메모는 수정하지 않았다. 화면의 `M3 합성 파서…`, 코드·테스트 설명,
영문 보고 항목은 기존 실험 데이터이며 제품 고정 문구가 아니다.
알려진 상태만 표시용으로 번역하고 사용자 정의 상태는 유지한다. 아이콘은 보고 상태를
구분하며 사실 검증을 뜻하지 않는다. `세션 보고`, `사용자 변경`, `가져온 기록`을 구별하고,
후보 리소스·미확인 상태·파일 오류·마지막 정상 기록 표시를 유지한다.

## 검증

- 메뉴 15개, 메뉴 설치 2개, 수집 실행 8개: 관련 테스트 25개 통과, 실패 0.
  메뉴 깊이·같은 제목·사용자 정의 상태·출처·핀 변경·last_good·상태 불변 회귀를 포함한다.
  이번 UI 변경을 위해 전체 268개 기준선 테스트나 실모델 테스트를 다시 실행하지 않았다.
- 설치된 rumps 0.4.0/PyObjC 12.2.2에서 실제 네이티브 뷰, 시스템 아이콘,
  같은 제목 두 항목의 NSMenu/래퍼 보존을 확인했다. 네이티브 재구성 100회 후
  남은 이전 콜백 레지스트리 항목은 0개였다.
- 실제 앱에서 태스크와 근거 상세를 열고 캡처했다. 메뉴를 연 채 6초 동안 수집 성공 시각이
  갱신되어도 선택한 태스크 메뉴·내용이 유지됐다. 닫았다 다시 열면 최신 투영을 표시했다.
  실제 수동 새로고침은 0.763초 후 성공했고, 오류 없음·태스크 상태 JSON 해시 불변을 확인했다.

  `screenshots/s04-task-final.png`, `screenshots/s04-evidence-full.png`에 있다.
