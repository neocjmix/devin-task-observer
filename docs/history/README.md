## 읽는 방법

현재 제품은 [BASELINE](../BASELINE.md), 후속 작업은 [BACKLOG](../BACKLOG.md), 구현 증거 색인은 [SLICES](../SLICES.md)를 따른다. 이 폴더의 현재·다음·미구현·normative는 **당시 범위의 표현**이다. 이미 달성한 목표를 새 백로그로 되살리거나 당시 테스트 수를 현재 결과로 읽지 않는다.

P0–M2는 이전 별도 모델·웹 경로, M3 누적 기록은 초기 NSMenu부터 협조형 보고·UI V2 전환까지의 증거다. 설계 변경안·평가는 사용자 결정의 맥락이며 최종 합의 규칙은 [현재 트랜잭션 계약](../STATE_TRANSACTION_CONTRACT.md)으로 정리했다. 원문 수치·판정·검증 범위를 보존하고 상대 링크만 새 위치에 맞췄다.

## 보존 규칙

새 결과를 과거 문서 끝에 계속 추가하지 않는다. 새 슬라이스·이슈·기준선에 기록한다. 과거 문서의 오탈자나 링크를 고칠 때에는 의미를 바꾸지 않는다. 과거 진술의 오류를 발견하면 당시 기록임을 유지하고 현재 판정을 별도 문서에 명시한다. 개인 원문·DB·인증정보·스크린샷은 이 폴더에도 넣지 않는다.
